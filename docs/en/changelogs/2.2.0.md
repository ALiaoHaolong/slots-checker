Added:
* Added view mode, which requires 2-level command permission.

Changed:
* Changed command grammar: `/slots-checker inventory|hotbar|ender|armor|offhand <player>` -> `/slots-checker inventory|hotbar|ender|armor|offhand <player> [view|edit]`.
* Now, the GUI title shows the current mode (`View Mode` or `Edit Mode`).
* When the player being checked dies, the GUI is no longer automatically closed.
* Updated mod description.
* Optimized code.

Fixed:
* When A checks B's ender chest, the GUI is closed if B opens any of the ender chest and A is not standing near this ender chest. ([#2](https://github.com/ALiaoHaolong/slots-checker/issues/2))
