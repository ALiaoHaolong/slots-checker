新增：
* 增加 view 模式，需要 2 级命令权限。

修改：
* 修改命令语法：`/slots-checker inventory|hotbar|ender|armor|offhand <player>` -> `/slots-checker inventory|hotbar|ender|armor|offhand <player> [view|edit]`。
* 现在，GUI 标题中会显示当前的模式（`查看模式` 或 `编辑模式`）。
* 被查看的玩家死亡后，不再自动关闭 GUI。
* 更新模组描述。
* 优化代码。

修复：
* 当 A 查看 B 的末影箱时，如果 B 打开任意一个末影箱，并且 A 不站在这个末影箱附近，则 GUI 会关闭。 ([#2](https://github.com/ALiaoHaolong/slots-checker/issues/2))
